# 프롬프트 관리 프로그램

Python 표준 기능만 사용한 초보자용 콘솔 프로그램입니다. 실행 중 프롬프트를
확인하고, 추가하고, 검색하고, 즐겨찾기 상태를 변경할 수 있습니다.

## 실행 방법

Python 3가 설치된 환경에서 저장소 루트에서 다음 명령을 실행합니다.

```bash
python main.py
```

## 제공 기능

- 기본 프롬프트 3개 보기
- 제목, 내용, 카테고리를 입력한 프롬프트 추가
- 제목과 내용으로 검색
- 즐겨찾기 추가 및 해제
- 즐겨찾기 목록 보기
- 기본 카테고리 선택 또는 직접 입력

데이터는 현재 프로그램이 실행되는 동안만 메모리에 저장됩니다. JSON 저장,
수정 및 삭제 기능은 현재 범위에 포함하지 않습니다.
